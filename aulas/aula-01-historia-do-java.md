## 1. Os primeiros computadores

Os primeiros computadores eram máquinas enormes, que ocupavam salas inteiras e possuíam capacidade de processamento limitada em comparação aos computadores atuais.

Inicialmente, a comunicação com essas máquinas acontecia por meio da **linguagem de máquina**, utilizando sequências de 0 e 1, conhecidas como código binário.

Com o avanço da tecnologia, surgiram novas formas de comunicação com os computadores, facilitando o desenvolvimento de programas.

## 2. Linguagens antigas

As primeiras linguagens de programação foram desenvolvidas para facilitar a comunicação entre o programador e o computador.

Alguns exemplos importantes:

- **Assembly:** linguagem de baixo nível, próxima às instruções executadas pelo processador.
- **FORTRAN (1957):** desenvolvida principalmente para cálculos científicos e matemáticos.
- **COBOL (1959):** criada para aplicações comerciais e administrativas.
- **LISP (1958):** utilizada em pesquisas matemáticas e inteligência artificial.
- **C (1972):** linguagem que influenciou diversas linguagens de programação posteriores.

Essas linguagens contribuíram para a evolução da programação e para o surgimento de tecnologias mais modernas.

## 3. Linguagens modernas

Com a evolução dos computadores, surgiram linguagens de programação mais próximas da linguagem humana, facilitando a escrita e a compreensão dos códigos.

Essas linguagens são chamadas de **linguagens de alto nível**.

Exemplos:

- Java;
- Python;
- JavaScript;
- C++;
- C#.

Cada linguagem possui características próprias e pode ser utilizada em diferentes áreas da tecnologia.

## 4. 1990 – Sun Microsystems

A história do Java está relacionada à empresa **Sun Microsystems**, responsável pelo desenvolvimento inicial da linguagem.

No início da década de 1990, a empresa iniciou um projeto com o objetivo de desenvolver uma tecnologia capaz de funcionar em diferentes dispositivos eletrônicos.

## 5. 1991 – GreenTalk

Em 1991, um grupo de engenheiros da Sun Microsystems, conhecido como **Green Team**, iniciou um projeto liderado por James Gosling.

O objetivo era desenvolver uma tecnologia para dispositivos eletrônicos, permitindo que diferentes equipamentos executassem programas.

A linguagem inicialmente desenvolvida recebeu o nome de **GreenTalk**.

Posteriormente, passou a ser conhecida como **Oak**.

## 6. 1994 – HTML, linguagens envolvidas e WebRunner

Em 1994, a equipe percebeu o potencial da tecnologia para utilização na internet, que estava em expansão.

Nesse período, foi desenvolvido o navegador **WebRunner**, posteriormente renomeado para **HotJava**, capaz de demonstrar a execução de aplicações Java na web.

### Tecnologias envolvidas

- **HTML:** linguagem de marcação utilizada para estruturar páginas da internet.
- **Java:** linguagem de programação utilizada para desenvolver aplicações.
- **WebRunner/HotJava:** navegador desenvolvido pela equipe da Sun Microsystems para demonstrar aplicações Java na web.

**Importante:** HTML não é uma linguagem de programação, mas uma linguagem de marcação.

## 7. Linguagem de alto nível

Java é uma linguagem de programação de alto nível.

Isso significa que sua sintaxe é mais próxima da linguagem humana, facilitando a escrita, a leitura e a compreensão das instruções.

Exemplo:

```java
System.out.println("Olá, mundo!");
```

O código acima exibe a mensagem:

```text
Olá, mundo!
```

As linguagens de alto nível facilitam o desenvolvimento porque não exigem que o programador escreva diretamente em código binário.

## 8. Código-fonte, compilador e código executável

Para que um programa Java seja executado, existe um processo de transformação do código escrito pelo programador.

### Código-fonte

É o conjunto de instruções escritas pelo programador em uma linguagem de programação.

Em Java, os arquivos de código-fonte possuem a extensão `.java`.

Exemplo: `Programa.java`.

### Compilador

É o programa responsável por traduzir o código-fonte Java para bytecode.

O compilador Java é chamado de `javac`.

### Bytecode

É o código intermediário gerado durante a compilação de um programa Java.

Ele é armazenado em arquivos com extensão `.class`.

### JVM (Java Virtual Machine)

É a Máquina Virtual Java, responsável por executar o bytecode.

A JVM permite que programas Java sejam executados em diferentes sistemas operacionais, desde que exista uma máquina virtual compatível.

### Processo de execução

```text
CÓDIGO-FONTE
Programa.java
      |
      v
COMPILADOR
javac
      |
      v
BYTECODE
Programa.class
      |
      v
JVM
      |
      v
PROGRAMA EXECUTADO
```

Uma das principais características do Java é a portabilidade, representada pela frase:

**Write Once, Run Anywhere (Escreva uma vez, execute em qualquer lugar).**

Isso significa que um programa Java pode ser executado em diferentes sistemas operacionais, desde que possuam uma JVM compatível.

## 9. Linguagem Oak

**Oak** foi o nome original da linguagem que posteriormente passou a ser conhecida como Java.

O nome significa carvalho, em inglês.

Durante o desenvolvimento do projeto, a equipe precisou substituir o nome Oak porque ele já estava registrado como marca.

Em 1995, a linguagem foi oficialmente apresentada com o nome Java.

- GreenTalk foi um dos primeiros nomes utilizados no projeto.

- O código-fonte Java possui extensão `.java`.
