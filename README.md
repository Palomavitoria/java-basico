# ☕ Java Básico

Repositório dedicado aos estudos e exercícios desenvolvidos durante o curso de **Java Básico**, do professor Gustavo Guanabara, disponível no Curso em Vídeo.

## 📚 Sobre o curso

O objetivo é desenvolver conhecimentos fundamentais da linguagem Java, compreender seus principais conceitos e adquirir experiência prática por meio de exercícios e pequenos projetos.

## 🛠️ Tecnologias e ferramentas

- Java SE 27
- JDK 27
- Apache NetBeans 32
- JavaFX 27
- Git e GitHub

## 📂 Organização do repositório


## 🎯 Conteúdos estudados

- Fundamentos da linguagem Java
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Programação Orientada a Objetos (POO)
- Interfaces gráficas com JavaFX

*Conteúdos atualizados conforme o andamento dos estudos.*
